## Р1. Что значит единица координат страницы

Координаты в любом варианте дробные и хранятся без потерь (у нас f64 + PCO, у стока f32 без сжатия),
поэтому точность и размер хранения от выбора не зависят. Выбирается только смысл единицы.

| Вариант                                                         | Как                          | Плюсы                                                                                                                                                                                                           | Минусы                                                                                                                                                         |
| --------------------------------------------------------------- | ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **А. 0…1 по каждой оси**                                        | x/ширина, y/высота           | ✅ не зависит ни от чего                                                                                                                                                                                        | ❌ неравномерно: круг становится эллипсом, радиус ластика и толщина разные по осям; все расстояния придётся пересчитывать с учётом пропорций — источник ошибок |
| **Б. 0…1 по ширине**                                            | x∈[0,1], y∈[0,высота/ширина] | ✅ равномерно; ✅ вписывание в экран тривиально                                                                                                                                                                 | ❌ единица бессмысленна физически: «толщина 0,0032» — надо отдельно хранить мм на единицу; ❌ шаг квантования в будущем будет выражен в долях ширины           |
| **В. Логические единицы** (как сейчас 1000×1400, или 1050×1400) | произвольный масштаб         | ✅ привычно коду; ✅ целые числа для сетки                                                                                                                                                                      | ❌ произвольный смысл, те же проблемы с мм, что у Б; ❌ импорт/экспорт стока — пересчёт ×1,714                                                                 |
| **Г. Пиксель при 300 dpi** (как у стока)                        | 1 единица = 1/300 дюйма      | ✅ физический смысл: `мм × 300/25,4`; ✅ на этой книге при масштабе 1 = пиксель экрана и координаты SDK; ✅ экспорт PNG 1:1 (1860×2480); ✅ импорт из стока без пересчёта; ✅ толщины и ластик в мм как у стока | ❌ на устройстве с другой плотностью (телефон ~400 dpi, монитор ~100 dpi) единица ≠ пиксель экрана — там нужен масштаб (он и так нужен для вписывания)         |
| **Д. Пиксель экрана устройства**, где создана страница          | как сток на практике         | ✅ совпадает с Г на этой книге                                                                                                                                                                                  | ❌ на другом устройстве с другой плотностью «пиксель» другого размера: заметка с телефона будет иметь толщины в чужих пикселях; физический смысл теряется      |
| **Е. Миллиметры** (или 0,1 мм)                                  | 1 единица = 1 мм             | ✅ самый понятный физический смысл                                                                                                                                                                              | ❌ страница 157,5×210 — дробные размеры; ❌ импорт стока ×0,0847; ❌ ни с чем на устройстве не совпадает                                                       |

**Рекомендация:** Г. Это сток, но с явно закреплённой плотностью 300 dpi, поэтому смысл единицы не
зависит от устройства (в отличие от Д).

## Р6. Оставшиеся мигания: нажатия пером по кнопкам

Механизм установлен (11-observations): касание пером кнопки в WebView сдвигается на ≥5 px →
прошивка ставит A2 в очередь → при ближайшей паузе пера (смена инструмента, удаление выделения)
A2 срабатывает → через 1 с полное обновление GC16.

| Вариант                                                                             | Плюсы                                                                                   | Минусы                                                                                                                                  |
| ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **А. `setAutoA2ForScrolling(false)` на время рукописной страницы**                  | ✅ убирает причину целиком (и для пальца); ✅ одна строка + восстановление              | ❌ скрытый метод Onyx (рефлексия, защита на других прошивках); ❌ прокрутка пальцем на этой странице без A2 (медленнее, но без вспышки) |
| **Б. Навсегда для всего WebView**                                                   | ✅ ещё проще                                                                            | ❌ текстовые заметки тоже теряют быстрый A2 при прокрутке (но и вспышку после неё)                                                      |
| **В. Перед каждой паузой сбрасывать очередь: `clearTransientUpdate(false)`**        | ✅ ничего не отключаем                                                                  | ❌ боремся с состоянием `ScrollHelper` прошивки: он всё равно через секунду шлёт свой clear с GC ❓; хрупко                             |
| **Г. Забирать у WebView и нажатия пером вне листа** (кнопки обрабатывать нативно)   | ✅ WebView пера не видит вообще                                                         | ❌ пришлось бы дублировать все нажатия пером в DOM — огромно и хрупко                                                                   |

## Р8. EinkWise для Tangleaf

Факты: сток `supportEAC=false` (решает прошивка), мы `true`. Нам прошивка ставит
`DEBOUNCER [1,5,80,400,20]` и считает касания (`DEBOUNCE_INC_REFRESH` → полная перерисовка каждые N
касаний по настройке «Full Refresh Frequency»). Профиль HD мы уже пишем сами.

| Вариант                                                                        | Плюсы                                                         | Минусы                                                                                                                                       |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **А. Оставить как есть**                                                       | ✅ ничего не делать; ✅ пользователь управляет через EinkWise | ❌ счётчик касаний даёт полные перерисовки, которых у стока нет                                                                              |
| **Б. Записать `supportEAC=false` в хранилище настроек** (как пишем профиль HD) | ✅ без root; ✅ как сток                                      | ❓ перезапишет ли прошивка при проверке (`ValidateAppConfigAction`); ❌ пропадут пользовательские настройки EinkWise для нас (DPI, контраст) |
| **В. Только отключить счётчик для нас** (параметры debouncer в конфиге)        | ✅ точечно                                                    | ❓ есть ли такой ключ, не проверено                                                                                                          |
| **Г. Через модуль LSPosed** (подменить `supportEAC` в `system_server`)         | ✅ точно работает                                             | ❌ только с root (Р9)                                                                                                                        |
| **Д. Попросить пользователя выставить «Full Refresh Frequency» = выкл**        | ✅ ноль кода                                                  | ❌ ручная настройка                                                                                                                          |

**Рекомендация:** сначала проверить Б на книге одним экспериментом (записать, перезапустить, посмотреть
`supportEAC(...) -> ` в логе PenTrace). Если держится — Б; иначе Д для всех и Г для root.
